# Готовность ML-генератора

Это список оставшихся проверок, не утверждение о готовности задачи.

## Подтверждено локально

- Метод generate, подготовка промпта, реальный адаптер OpenRouter, сбор SSE и валидация M1 v2 реализованы.
- Типы, количество, ID и ключи ответов проверяются программой; неполный результат не возвращается как успех.
- Этапы передаются callback; хранение задач, WebSocket и запись теста относятся к backend.
- После уточнения правил выбранного типа прошли 50 выбранных unit-тестов и bootJar. Это не CI.

## Открытые проблемы

- Бесплатная модель возвращает single-choice по смыслу вместо multiple-choice; безопасное отклонение работает, успешная генерация этого типа не подтверждена последними сериями.
- Средняя сложность не соблюдается устойчиво: воспроизведение определений ошибочно считается достаточным. Проверка той же моделью пропускает такие дефекты.
- Результаты отдельных успешных запросов не подтверждают стабильность модели; таймауты и ошибки провайдера возможны.
- Отключение reasoning сократило время некоторых запросов; повторное включение дало таймауты и пока не подтвердило улучшения качества. Сравнение режимов фиксируется отдельно.
- Реальные проверки 10 вопросов и всех сложностей после финального выбора модели ещё не выполнены.
- Интеграция BE → generate → сохранение → COMPLETED и доставка этапов FE не подтверждены.

## Порядок дальнейшей работы

1. Сравнить выбранную модель с reasoning и без него на одинаковом материале/параметрах. Сохранить успехи и ошибки, проверить ответы человеком.
2. Если режим не решает проблему, сравнить другую явно бесплатную модель через тот же ModelClient; контракт backend не менять. Не подключать платный fallback автоматически.
3. После выбора работоспособной настройки проверить три типа, 5/10 вопросов, все уровни сложности и несколько учебных материалов. Для фактов/ответов проверять исходник, для сложности — реальные действия ученика, для multiple-choice — каждый вариант отдельно.
4. С backend проверить минимальный настоящий вызов, безопасную ошибку, этапы и успешное сохранение. WebSocket реализуют BE/FE; VALIDATED не означает, что тест сохранён.
5. Обновить доказательства в README/документации, создать PR после разрешения на push. Нужны человеческий аппрув и комментарий ревьюера, зелёный CI со ссылкой, проверка после merge и удаление завершённой ветки.

M1 v2: [описание](ml-output-m1-v2.md). Подключение: [памятка BE](be-ml-handoff.md).
Прогоны: [история проверок](ml-generator.md), JSON в ml-examples/.

Для сравнения бесплатных моделей: `./scripts/ml-live.ps1 -Type all -Model <точный-id:free>`.
Флаг `-Reasoning` включает рассуждение только для эксперимента. Ключ вводится скрыто.
Модель и режим сохраняются в безопасных метаданных прогона. Это не автоматический fallback.
