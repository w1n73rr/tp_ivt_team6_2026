## Изменения к разделам «Текущее состояние», «Страницы», «Роутинг»

- Авторизация /login и регистрация /register подключены к backend API в dev, статус «заглушка» для этих форм устарел.
- POST /api/auth/login принимает username/password; POST /api/auth/register — username/email/password. Оба возвращают JWT в поле token.
- После успешного login с JWT выполняется Angular Router.navigateByUrl('/dashboard'). Полная перезагрузка страницы не выполняется.
- / остаётся публичной главной страницей. /dashboard — пользовательский раздел; содержимое dashboard пока является заглушкой.
- JWT хранится в памяти корневого AuthService и сохраняется при SPA-переходе. Сохранение после F5 не реализовано и не входит в задачу.
- При ошибках HTTP 400/401/403/5xx пользователь остаётся на /login и видит сообщение об ошибке. Ответ без token также не приводит к переходу.
- Guard, logout, материалы и загрузка материалов не входят в задачу.
