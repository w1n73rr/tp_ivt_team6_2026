# Отчёт: API параметров генерации

Дата локальной проверки: 03.11.2026. Реализация сохранена коммитом 80cd65c, затем
объединена с обновлениями origin/dev. Результаты первичной проверки до объединения
сохранены ниже; повторные проверки объединённой версии перечислены в конце.
PR и ревью другого участника этим отчётом не подтверждаются.

## Выполнено

- Реализован защищённый JWT `GET /api/generation/parameters`, чтение доступности и
  defaults из БД на каждый запрос, Cache-Control: no-store.
- Flyway V4 создаёт и заполняет справочник: 5/10, EASY/MEDIUM/HARD,
  SINGLE_CHOICE/MULTIPLE_CHOICE/TRUE_FALSE. Все начальные варианты доступны.
- Ровно один тип задаётся полем questionType. GenerateQuizRequest больше не содержит
  темы, персонализацию и массив questionTypes; лишние поля отклоняются.
- Чтение и проверка POST используют общий GenerationParametersService и одну БД.
- SQL-скрипт изменения справочника выполняет транзакцию, блокировку и проверку
  default; некорректные изменения не сохраняются. Административного UI/API нет.
- Для настроек запусков добавлены отдельная таблица снимков и insert/read, метод
  saveForRun; настройки хранятся значениями и не меняются вслед за справочником.
- Подготовлено преобразование кодов настроек к ML-контракту. ML-модуль получен
  из origin/dev, но HTTP-очередь и WebSocket пока не подключены; допустимый POST возвращает 501 после проверки,
  не создаёт снимок/задачу и не выставляет COMPLETED.
- README полностью обновлён: требования, .env.example, docker compose up,
  регистрация, GET, проверка запрета, изменение БД и тесты. Секреты не добавлялись;
  .env игнорируется, примеры содержат только локальные тестовые значения.
