# TY5 — подключение ML, 02.11.2026

В текущей рабочей копии backend подключён к Java-пакету ML. Полная приёмка TY5
ещё не подтверждена: ниже отделены реализация и реально выполненные проверки.

Что изменено:

- QuizGeneratorAdapter вызывает QuizGenerator.generate(request, callback): текст,
  настройки, materialId и jobId/requestId. Промпт/OpenRouter обрабатывает ML-пакет.
- Генерация идёт в ограниченном executor, HTTP сразу возвращает 202/jobId.
- Callback без SQL/сокетов передаёт этапы в ограниченную очередь. Отдельная обработка
  сохраняет stage/detailStage/version. Старые события и терминальные задачи защищены.
- WebSocket /api/ws/generation проверяет Origin, JWT и владельца. Передаёт снимки
  независимо от ML; HTTP GET восстанавливает состояние. FE-экран не подключался.
- M1 v2 сохраняется с correctOptionIds и UUID вопросов/вариантов. Правильные ответы
  не попадают в публичный список/статус. Тест и COMPLETED записываются атомарно.
- V5 добавляет этапы/версию, старые миграции не изменены. Прерванная неизвестная
  операция к модели автоматически не повторяется: GENERATION_INTERRUPTED.
- Word: w:tab сохраняется как табуляция, w:br/w:cr — как переносы строк.
- README, backend/GENERATION.md, OpenAPI, Compose и .env.example обновлены.
  Ключ OpenRouter только серверный, пример пустой. Реальные секреты не добавлялись.
