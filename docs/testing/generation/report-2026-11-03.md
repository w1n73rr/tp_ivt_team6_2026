Он не является результатом UI-автотеста. Основной код теперь находится
в QuizGenerationUiTest и Page Object модуля ui-tests.

**Ветка:** `feature/generation-test-cases`.
**SHA backend/frontend:** `e5f98eb995449f47aef722deea1fbd25b65b61ce` (dev).
Новые кейсы и проверочный клиент находятся в рабочем дереве поверх этого SHA.

## Окружение

Отдельный Docker Compose project `generation-acceptance`, новая PostgreSQL 16,
SeaweedFS 4.48, настоящие backend и OpenRouter; моки не использовались.
Frontend собран через npm; backend bootJar собран Java 25/Gradle 9.1.0.
Из-за сетевого таймаута Maven Central новые зависимости получены через
зеркало Google с локальным init-script вне репозитория. Runtime backend
упакован поверх существующего Java runtime-образа, с новым app.jar и SHA label;
это не чистая Docker-сборка builder-стадии с нуля.

- Backend: `http://localhost:18081`.
- Frontend: `http://localhost:13001`.
- Модель: `nvidia/nemotron-3.5-super-vl:free`, reasoning=false, один worker.
- Материал: [lecture.txt](lecture.txt), учебный текст о тестировании ПО;
  точный размер записан в JSON. Это smoke-замена предметных M1–M3.
- Настройки обоих запусков: 5 / MEDIUM / SINGLE_CHOICE.
- Каждый запуск использовал новые тестовые аккаунты, материал и ключ
  идемпотентности. Записи оставлены на отдельном стенде для проверки.

## Оценка содержания успешного результата

Сверены все вопросы, каждый ключ и объяснение с lecture.txt. Правильные
ответы соответствуют источнику. Смысловых дублей между пятью вопросами нет.

| Вопрос | Ключ по источнику | Оценка сложности |
|---|---|---|
| q1: что проверяет интеграционное тестирование | Взаимодействие компонентов | EASY: прямое определение |
| q2: что проверяет негативный тест | Недопустимые данные/условия отказа | EASY: прямое определение |
| q3: что включает тест-кейс | Предусловия, данные, шаги, ожидаемый результат | EASY: воспроизведение перечня |
| q4: что позволяет проверить мок | Поведение компонента в контролируемых условиях | EASY: прямое определение |
| q5: что подтверждает успешный тест | Проверенный сценарий, а не отсутствие всех дефектов | EASY: воспроизведение тезиса |

**Техническая интеграция: PASSED во втором запуске. Соответствие MEDIUM:
не подтверждено, замечание к качеству ML.** Нет задач на применение правил
в конкретной ситуации. В q3 правильный ответ заметно полнее альтернатив,
в q5 длинный правильный вариант даёт дополнительную подсказку.

Наблюдения для передачи владельцу ML: (1) реальный запуск может завершиться
INVALID_MODEL_OUTPUT; (2) MEDIUM-серия содержит только вопросы уровня EASY.
Задачи в трекере этим прогоном не создавались; это локальные замечания,
а не зарегистрированные дефекты с номерами.

## Что остаётся непроверенным

Подготовлены описания всех TC-GEN-01–12, но эта серия не является прогоном
всего набора. Не выполнены реальная генерация PDF/DOCX, 10 вопросов,
другие типы/сложности, управляемые ошибки извлечения/сохранения и UI-моки.
Не измерялся счётчик обращений к ML для отклонённых запросов.

Frontend на проверяемом SHA использует DemoGenerationSource и DemoTestsSource.
Поэтому реальная UI-таблица после обновления и сквозной запуск из формы
**заблокированы интеграцией FE**. Повтор GET списка и SQL-сохранение проверены,
но не выдаются за пройденную проверку UI-таблицы.

Частичные 7 из 10 не поддерживаются текущим MlResultValidator (требуется
точное количество); переход к первому вопросу из исходного документа
также не подтверждён. Оба расхождения явно оставлены в кейсах для решения PO.

Кейсы и отчёт доступны в репозитории локально. Публикация, прикрепление к
задаче, согласование PO, человеческое ревью и CI этим прогоном не выполнены.
Ключи, JWT и env-файлы в артефакты не включены.
