# Selenide: генерация теста, 03.11.2026

Ветка feature/generation-test-cases, приложение dev e5f98eb.
Стенд http://localhost:13001, видимый Chrome 156.0.8078.80,
ChromeDriver той же версии, Java 21, Selenide 7.18.2.

Основной класс: QuizGenerationUiTest. Все предусловия создаются браузером:
регистрация отдельного аккаунта, загрузка UTF-8 TXT, создание предмета,
переход к настройкам выбранного материала. Ключ ML тесту не передаётся.

| Проверка | Фактический результат |
|---|---|
| Карточка выбранного материала, формат/размер, возврат | PASSED |
| Количество/сложности, одиночный тип «Один ответ» | PASSED |
| Количество/сложности, одиночный тип «Несколько ответов» | PASSED |
| Количество/сложности, одиночный тип «Верно/неверно» | PASSED |
| Пустое название — ошибка, ожидание не открывается | PASSED после исправления очистки поля; отдельный повтор метода успешен |
| Реальный UI → BE → ML, COMPLETED, таблица после refresh | BLOCKED: DemoGenerationSource, явный AssertionFailedError |

Полный повтор класса после обновления драйвера подтвердил четыре
проверки и блокировку интеграции. Затем исправлено сравнение пустого
значения поля; целевой повтор rejectEmptyName завершился BUILD SUCCESSFUL.
Полный класс после последней правки повторно не запускался.

Начальные таймауты навигации воспроизводились с Chrome 156 и старым
ChromeDriver 155. Локально установлен официальный ChromeDriver 156;
его путь и адрес стенда сохранены в игнорируемом ui.local.properties.

GenerationPage/TestsPage содержат публичные поля SelenideElement с @Name
и XPath. MaterialRow дополнен generateButton. GenerationTraffic наблюдает
настоящий POST браузера; только после него использует авторизацию
тестового пользователя для проверки статуса и списка. Он не запускает
генерацию вместо UI и не выводит JWT в диагностические сообщения.

В E2E написаны проверки отправленных параметров, materialId/имени,
COMPLETED с quizId, единственной записи API и UI-таблицы после обновления.
На текущем frontend выполнение этих последующих шагов не достигнуто:
тест останавливается на явной проверке demo-режима. Их успешность
этим прогоном не подтверждена. Демо-кнопки тест не нажимает.

Набор пока не покрывает все TC-GEN-01–12: управляемые ошибки,
API-негативные сценарии и все форматы требуют отдельной реализации
после подключения настоящего frontend. Демонстрация не заменяет эти проверки.
Предыдущие JSON относятся к отдельному API-прогону; Python-клиент удалён.
Коммит и push не выполнялись.
