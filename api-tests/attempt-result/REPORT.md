## Инструкция и известные ограничения

Актуальная инструкция — api-tests/attempt-result/README.md. Есть отдельные команды первой подготовки, повторного прогона без Docker-сборки, запуска из IDE и остановки. Секреты читаются из игнорируемого .env.result-api.local, содержимое в отчёт не включается. Стенд оставлен работающим для повторения.

При локальной подготовке использован уже имеющийся образ Java 25 tpivt-81-server-check:dev и кеш Gradle tpivt-79-gradle через локальный override вне репозитория. Исходники актуального backend размещены в чистой /suite. Окончательная команда Gradle wrapper из Dockerfile и готовность Compose --wait проверены. Чистая загрузка официального eclipse-temurin:25-jdk и зависимостей на другом компьютере отдельно не выполнялась. README использует официальный образ и отдельный кеш по умолчанию.

В первой подготовке кеша не хватило для поиска Spring Boot через Plugin Portal. В конфигурацию добавлен init-скрипт с Maven Central перед Plugin Portal, успешный запуск проверен. Изначальные ошибки подготовки теста (обязательное subjectName и пустой fieldErrors в безопасном ответе) исправлены в тестовом коде и перепроверены.

Приложенные UI-кейсы предусматривают частичные баллы C/K. Текущий опубликованный OpenAPI определяет целочисленную оценку 0/1 и процент по полностью правильным вопросам. Требуется согласование аналитика/PO и BE. Расхождение отмечено как вопрос контракта; отдельная задача в Сфере ещё не создана. В пределах проверенного OpenAPI дефектов API не обнаружено.
