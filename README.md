## Автотестирование

В проекте создано выделенное пространство для API и интеграционных автотестов.

### Структура проекта автотестов (`src/test/java/tech/genna/TY3`):
- `config/` — конфигурация REST Assured и спецификации HTTP-запросов.
- `client/` — API-клиенты эндпоинтов приложения.
- `tests/base/` — базовые классы инициализации Spring-контекста.
- `tests/auth/` — тесты авторизации и аутентификации.

### Локальный запуск:
Запуск всех автотестов из консоли:
```bash
.\gradlew test
