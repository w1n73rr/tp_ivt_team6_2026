# API: справочники предметов и тегов

Все запросы требуют Bearer JWT. Успешные GET-запросы возвращают `200 OK` и JSON-массив. Пустой справочник возвращается как `[]`.

## Получить предметы

`GET /api/subjects`

Возвращает предметы текущего пользователя, отсортированные по названию.

```json
[
  { "id": "d290f1ee-6c54-4b01-90e6-d701748f0851", "name": "Математика" }
]
```

## Получить теги

`GET /api/tags`

Возвращает теги, связанные с предметами текущего пользователя, отсортированные по названию.

```json
[
  { "id": "1dd55c39-6512-4a5f-9bb7-0cf3d45bb6d2", "name": "Алгебра" }
]
```

Оба endpoint возвращают `[]`, если у пользователя пока нет соответствующих записей. Неавторизованный запрос получает `401 Unauthorized`.
