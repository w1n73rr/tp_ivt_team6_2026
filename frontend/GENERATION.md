# Генерация: интеграция frontend

Форма читает доступность и defaults из `GET /api/generation/parameters`.
Пользователь выбирает материал, название, 5/10 вопросов, сложность и ровно один тип.
`POST /api/quizzes` передаёт UUID `Idempotency-Key`; backend возвращает ID задачи.
Frontend опрашивает `GET /api/generation-jobs/{id}` каждые две секунды.
Проценты не вычисляются; показываются фактические status/stage/detailStage.

Принятые настройки и задача сохраняются в sessionStorage отдельно по владельцу
и материалу. Возврат/reload не запускает модель повторно. Неизвестный исход POST
сохраняет ключ для точного повтора; после подтверждённого FAILED повтор создаёт новую задачу.
Временная ошибка чтения статуса не выдаётся за терминальный отказ генерации.
401 прекращает опрос и предлагает вход с безопасным возвратом к материалу.

## Результат

Успех требует COMPLETED, quizId и подтверждённую запись в списке тестов.
Backend принимает только точное количество вопросов; частичный результат неуспешен.
Показывается «Тест готов», отключённая кнопка «Перейти к тесту» и ссылка «Все тесты».
Автоматического перехода к первому вопросу нет: прохождение пока не реализовано.
Терминальная ошибка открывает экран ошибки; повтор сохраняет параметры формы.
Завершение покинутой задачи не должно перенаправлять пользователя с другой страницы.

Список загружает собственные записи из `GET /api/quizzes`.
Демонстрационные провайдеры нужны для компонентных тестов и не подменяют реальный API.
Переименование/удаление реальных тестов зависят от соответствующих backend-операций.
Список не раскрывает вопросы и правильные ответы. Ключ OpenRouter в браузер не передаётся.

## Проверка

Из корня: `npm --prefix frontend ci`, `npm --prefix frontend test -- --watch=false`,
`npm --prefix frontend run build`. Браузерные сценарии: [tests/ui](../tests/ui/README.md).
Управляемые тесты проверяют реакцию интерфейса на успешные/неуспешные исходы;
настоящий вызов модели отдельно проверяется через API перед релизом.
Контракт и ограничения: [backend/GENERATION.md](../backend/GENERATION.md).
